# 論文メモ: 先行研究の recall と QB の比較

2026-11-10 作成。QB（sr-query-builder-plugin）の論文はまだ書き始めていない。論文の売りの一つとして残すメモ。

## 主張したいこと（本人の指示）

AI による検索式作成の先行研究をまとめた AHRQ の rapid review では、recall の中央値が 25% にとどまる。QB はこれを大きく上回る。

## 先行研究（比較の相手）

- 書誌: Adam GP, Kuhn E, Davies M, et al. Artificial Intelligence and Machine Learning Tools To (Semi-)Automate Evidence Synthesis: A Rapid Review and Evidence Map, 2026 Review Update [Internet]. Rockville (MD): Agency for Healthcare Research and Quality (US); 2026 Aug.
- URL: https://www.ncbi.nlm.nih.gov/books/NBK625909/ （該当節 #ch3.s2、表3 https://www.ncbi.nlm.nih.gov/books/NBK625909/table/ch3.tab1/ ）
- 2026-11-10 に内蔵ブラウザで原文を開いて確認した（WebFetch は reCAPTCHA の画面で弾かれる。ブラウザでは数秒待つと自動で通った）。

| 項目 | 値 |

| 研究数（ツール・モデル数） | 24（32） |
| 比較対照 | Human-developed search strategies |

| NNR（n=14） | 中央値 29（13〜56） |

- 脚注2の定義: recall = 正しく同定された relevant citations の割合。
- 3.2.2 節の記述: 参照基準はすべて、公表された SR の組み入れ文献。15 研究が LLM による検索式の生成、7 研究がデータベースを検索して関連文献を返すモデルを評価。結論は "do not approach the accuracy of search queries created by research librarians"。

### 中央値の陰にある、高い recall の研究（論文で反論されないために必ず触れる）

3.2.2 節に、中央値よりずっと高い例が書かれている。「圧倒的」と書くなら、これらとの違いを説明できる必要がある。

- zero-shot の human-in-the-loop（人が式を直せる）3 研究: recall 60〜80%。
- GPT-4 で recall 91%。ただし NNR 500（広く網を張っただけ）。
- チャットで PICO を聞き出す方式: recall 69%。
- DeepSeek-V3 と Kimi-K2 を使う多段のエンドツーエンドのツール: recall 83%。
- 既存の検索式や関連研究のデータで事前学習したモデル（4 研究）: mean / median recall 85〜97%、precision は 0.001（NNR 1000）〜0.09（NNR 11）。
- zero-shot は概して低く、事前学習や few-shot（関連文献をプロンプトに入れる）が高い、という整理。

## 論文に書く前に詰めること

1. 比較の土俵が違う。AHRQ の数字は 24 研究の中央値で、データベース・テーマ・正解の定義（論文単位か研究単位か）・検索日の扱いが研究ごとに違う。QB のベンチと直接は比べられない。「同じ条件で比べると」ではなく「先行研究の報告の範囲（中央値 25%、最高でも 83〜97%）に対して」と書く。
2. 固定小集合 20 件は手順書の選別に繰り返し使った集合なので、そこの数値（Opus 0.934 など）は楽観的。本文の主張は検証群か試験群の数値で行う。
3. QB の precision・NNR は直接は測っていない。ヒット件数と組み入れ研究数から計算できるので、AHRQ の表の NNR と並べるなら算出する。
4. AHRQ の比較対照は人手の式で、QB のベンチも原著の人手の式を並べている。QB は人手の式（0.914）を少し下回るので、「人手の式に並ぶ」までが言える範囲。「上回る」とは書けない。
5. 「圧倒的」の表現は、中央値 25% に対しては妥当だが、上の高い例（事前学習モデル 85〜97%、エンドツーエンド 83%）があるので、本文では「zero-shot の LLM を使う多くの先行例より大幅に高く、事前学習を要する手法と同じ水準を、事前学習なし・人手の式と同じ件数で達成」のように、条件を付けて書くのが安全。
6. 先行研究の個別の論文（91% の GPT-4、83% のエンドツーエンドのツール、事前学習の 4 研究）は、AHRQ の引用番号（34〜57）から原著を引いて確認する。
