## cue 01
This is the main view of the SR Query Builder Plugin. The side navigation lists all 10 steps of building a search formula, from protocol input through block approval, seed paper registration, formula generation and verification, to export. Until a project is selected, most of these items are grayed out.

## cue 02
When no project is selected, the home screen shows this notice. Clicking "Open another project..." opens the project creation/selection screen in a new tab.

## cue 03
Clicking the title in the top left always brings you back to this home screen. The Settings button in the top right lets you register the API keys used to generate search formulas.
