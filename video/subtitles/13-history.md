## cue 01
Version history. Every search strategy you build is kept here, newest first, with a marker on the one currently loaded. It records which version each one derives from, who created it, and the reason for the change you wrote in the edit memo.

## cue 02
Each row shows the beginning of the strategy so you can compare them. Press "Load this version" to go back to that point and resume work. Older versions are never deleted.

## cue 03
Besides the API keys covered in chapter 2, the settings screen also lets you add models. Register an OpenRouter model ID and it joins the list of available models. If formula generation isn't going well, trying a different model is one option.

## cue 04
If you get stuck, the help page has explanations of each screen and answers to common questions. There's a link in the video description.
